# Linuka Bandara Portfolio Redesign

This version was redesigned around the visual direction of dinuja.online without copying it pixel-for-pixel.

Included:
- Floating pill navbar with Home / About / Education / Projects / GitHub / Contact
- Large two-line hero name
- Typing effect under the name cycling through roles
- About + technology grid
- Education section
- Featured projects populated from the public @LinukaBandara GitHub profile
- Live and source links for DispatchArc, BGS AgriStock, Suranga Gems and ARK II
- GitHub-style activity section
- Responsive mobile navigation
- Contact CTA and social links
- Existing project preview images retained from the supplied workspace

Run locally:
1. npm install
2. npm run dev
